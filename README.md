# Active Directory Enterprise Lab

This project documents the setup and administration of a Windows Server 2022 Active Directory lab environment built in VirtualBox.

The goal of this lab was to practice foundational IT Support, Help Desk, and junior system administration tasks in a Windows domain environment.

## Project Parts

- [Part 1 – Environment Setup](./01-environment-setup/README.md)
- [Part 2 – Domain Deployment](./02-domain-deployment/README.md)
- [Part 3 – User Management](./03-user-management/README.md)

## Skills Practiced

- Windows Server administration
- Virtual machine setup in VirtualBox
- Static IP configuration
- Active Directory Domain Services (AD DS)
- DNS integration with AD
- Domain Controller deployment
- User and group administration
- Password reset workflows
- Basic identity and access management
